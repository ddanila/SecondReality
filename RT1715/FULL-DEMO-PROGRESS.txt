Host entry points
-----------------
build/host-python/bin/python full_build.py --output build/full-remake
build/host-python/bin/python full_capture.py build/full-remake/dos \
  --output build/full-remake/capture --cycles 300000 --timeout 1800
build/host-python/bin/python full_compare.py build/full-reference/capture \
  build/full-remake/capture review/part.mp4 --start SECONDS --duration SECONDS

Run from RT1715. The native Watcom compiler, linker and JWasm are resolved
by build.py from the sibling msdos toolchain. No compiler runs inside DOS.
DOSBox-X uses SDL dummy video/audio and the existing no-confirmation config.
The capture watchdog stops on DOS CPU exceptions and timeouts.
Do not run several high-cycle DOSBox instances concurrently: they compete
for host CPU and make test timeouts misleading.

Released EXEs are unpacked on the host with Deark (local build/toolchain/deark,
upstream https://github.com/jsummers/deark, tested commit
8997059c4f32af79978fb6c83be7c1c26c259afa). Some have two compression layers,
others only PKLITE. The source hash controls the decompression cache.

Evidence and review rules
-------------------------
assets/full-demo/reference-cues.json records the full original playback.
Each capture retains its continuous WAV, mode-specific AVI files, paired
scene-entry/exit tracker positions and retrace counts, and result.json.
Smoke tests start individual scenes at a convenient tracker order; these
are visual checks, not timing references. The launcher waits for the requested order and row before entering a scene,
so stale positions from asynchronous music startup cannot select a wrong cue.
Comparisons use one original audio track and waveform alignment at seven
windows. At least five of seven audible windows must have correlation >=0.65
(or all three if only three are audible); every window remains in the report.
Never stretch video or audio to conceal drift. Drift over one VGA frame among
reliable windows is rejected. Module restarts need separate validation.
The copper-interrupt counter is useful for scene diagnostics; it can lose
counts while DOS extender code masks interrupts, so its post-flyover delta
is not a measurement of video frame drift. Tracker cues and audio govern sync.
